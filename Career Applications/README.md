# Targeted Internship Applications

This folder contains role-specific resumes and cover letters built from verified candidate materials and the current cybersecurity portfolio.

## Included targets

- [NYS DHSES Internship](NYS%20DHSES%20-%20Internship/)
- [NYSED Software Developer](NYSED%20-%20Software%20Developer/)
- [Adobe Research Scientist Engineer Intern](Adobe%20-%20Research%20Scientist%20Engineer%20Intern/)

Each folder contains a tailored `Resume.md` and `Cover_Letter.md`. The documents use the candidate's actual education, work history, certifications, projects, and current Home SIEM work. Claims are not presented as completed until the underlying project is complete.

The visual resume template supplied by the candidate is documented as the design direction for a later DOCX/PDF rendering pass. The Markdown versions are the ATS-friendly source documents.
