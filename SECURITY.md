# Security and Responsible Use

This repository is an educational cybersecurity portfolio. All testing must be performed only against systems owned by the user, intentionally created for the lab, or explicitly authorized for testing.

## Required safeguards

- Keep lab networks isolated from production and personal systems.
- Use synthetic or sanitized data in public documentation.
- Never commit credentials, tokens, private keys, or personal information.
- Use least privilege and non-administrative accounts where practical.
- Take VM snapshots before destructive or difficult-to-reverse exercises.
- Verify targets before running scanners, simulations, or payloads.
- Do not publish exploit details or offensive artifacts that are not necessary to demonstrate the learning outcome.

Potential security issues in the repository should be handled privately and should not be tested against third-party infrastructure.
