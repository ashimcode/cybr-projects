# Graphiti Memory Model

This project will store durable, non-secret knowledge in a documented Graphiti namespace.

Planned entities include:

- lab hosts and services;
- telemetry sources and destinations;
- OSI layers and protocols;
- detections and test cases;
- investigation findings;
- hardening decisions;
- evidence artifacts;
- lessons learned and interview explanations.

Credentials, tokens, private keys, and unnecessary personal data do not belong in project memory.
