# Learning Checkpoints

## Phase 1

### Recall

- What is the difference between a log, an event, an alert, a detection, and an incident?
- What does Sysmon add to standard Windows event logging?

### Prediction

- What should happen to a test event as it moves from the Windows VM to the SIEM?
- Which service or network boundary could prevent the event from arriving?

### Teach-back

Explain the complete telemetry path as if presenting the architecture to a SOC hiring manager.

## Phase 2 and later

Each phase will add prediction, verification, troubleshooting, and teach-back questions based on the actual configuration and evidence produced.
