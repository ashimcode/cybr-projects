# Evidence Handling

Only sanitized evidence belongs in this directory.

Each published evidence item should include:

- a descriptive filename;
- the date captured;
- the project phase;
- what the item proves;
- sanitization notes;
- the related report or checklist.

Do not publish credentials, tokens, private keys, personal data, real email addresses, unapproved IP addresses, host identifiers, proprietary data, raw packet captures, or unredacted event logs.

Video evidence should demonstrate the workflow and outcome without revealing secrets or unrelated personal information.
